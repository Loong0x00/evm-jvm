# Minecraft-first Pattern.compile(String) P36 plan

## Scope and provenance

This stage is an append-only guest-Java implementation based only on the exact parent-provided, source-only P35 snapshot at `../pattern-source-base-p35/` (manifest verified before use). That baseline remains immutable. The task is the measured `java/util/regex/Pattern.compile(Ljava/lang/String;)Ljava/util/regex/Pattern;` dependency; no original archive/class/resource/world/checkpoint/receipt/binding data is an input. Generated fixtures are the only execution/oracle inputs.

The profile appends genuine Java 8 `Pattern` and `PatternSyntaxException` images after the 101 existing bootstrap images. All old bootstrap class bytes and slot order are invariant. The generated-only q1 syntax/error witness exceeded the previous harness's 10,000-call guard and 1,200-second wall budget; both test-driver quotas (not semantic blockers) were coherently doubled to 20,000 calls/2,400 seconds. The exact150/1,063,930-byte Pattern compile measured `LC0ControlError(7)` under a 1B call allowance, so the independent test-only call allowance was doubled to 2B. The final worker gate `runs/p36-pattern-bootstrap-008/` passed at 20,000 calls/2,400 seconds/2B; these allowances do not alter accepted EVM/runtime/raw/checkpoint semantics or quotas. Earlier failures and retries are preserved under `runs/p36-pattern-bootstrap-001` through `-007`. No new operational native binding, EVM opcode/gas/state/consensus change, coordinator storage/ABI change, host regex callback, matching engine, or Matcher/split implementation is in scope. Runtime ceiling remains 1 MiB and checkpoint ceiling remains 2 MiB; the measured test-only budget is 2B/call and 2,400 seconds.

## Provisional grammar

The supported compiler family is a regular, eagerly tokenized sequence consisting of an optional leading `(?i)` inline modifier followed by zero or more UTF-16 literal code units and positive/negative character classes whose members are UTF-16 literals or inclusive literal ranges. Non-alphanumeric escaped punctuation is accepted as a quoted literal; alphanumeric escapes, nested classes/intersection, other inline modes, and regex operators outside classes are valid-but-unsupported and atomically refused. CASE_INSENSITIVE is Java's ASCII-only behavior (no UNICODE_CASE). The required measured literal `(?i)§[0-9A-FK-OR]` is in-family. The EVM checkpoint audit compares all eight exact compiled token arrays from the generated matrix.

Supported syntax errors (including unclosed/empty classes and descending ranges) must throw a guest `PatternSyntaxException` extending the canonical guest `IllegalArgumentException`, with exact `description`, `pattern`, and `index` state. Null input must throw guest NPE. Valid syntax outside this grammar must take an ordinary atomic `CallError(4)` through a private, unbound `unsupportedBranch` native declaration; it is not reported as a Java syntax exception or converted into a fake compiled Pattern. `pattern()`, `flags()`, and `toString()` are implemented; matcher, matching, split, flags-overload and other omitted Pattern APIs remain typed refusals.

## Verification gates

1. Verify the exact nine-file P35 source-only snapshot manifest/pins and keep it unchanged. The P36 verifier recompiles both appended images from Java 8 source, proves the exact two-image engine delta, and binds the coordinator to the new engine codehash/domain.
2. Rebuild source-authenticated Java 8 class images; verify classfile major version, class/super/interfaces/fields/methods, eager compiled-token writes, exception state, and no unexpected native methods.
3. Rebuild the P36 engine/coordinator with pinned solc settings; prove P35 ABI/storage layouts and every old bootstrap image/leaf/slot are unchanged, then derive the new 103-leaf root. Runtime must remain <=1 MiB.
4. Use generated Java 8 oracle probes for compile validity, pattern(), flags(), and PatternSyntaxException data; use generated EVM fixtures for supported grammar, syntax errors, null, valid-outside-grammar refusal, omitted overloads, and raw Pattern/PSE replacements.
5. Run direct q1/q7/q4096/q65536 and fresh-process reopen canonical-receipt/equivalence checks under the pinned 20,000-call/2,400-second/2B test-driver allowances, the normal CREATE coordinator route, and small retained HashMap/IdentityHashMap/Math-double/packed/sparse/raw-envelope controls.
6. Preserve all source/build/test reports under this stage. Parent owns independent P36 rebuild, full-root validation, and the actual untouched-original continuation after handoff. No world/Done claim.
