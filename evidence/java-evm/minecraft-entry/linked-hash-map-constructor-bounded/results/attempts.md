# Preserved candidate attempts and harness observations

- A first javac invocation attempted to compile the accepted minimal `HashMap.java` together with the candidate against the stock Java 8 `Map` definition. That failed because the accepted minimal P48 `Map` image intentionally does not declare the Java 8 default methods annotated by `@Override` in the accepted HashMap source. The correct image build compiles only the LinkedHashMap leaf against the stock Java 8 API (`javac 1.8.0_504 -g:none -source 8 -target 8`); its superclass/generic/member descriptors match the existing P48 image. No HashMap source/image was changed. A later fixture javac command initially had a missing output directory; the fixture build was rerun successfully.
- Initial q1/q16 refusal-world shell loops watched for receipt files inside the durable Session directory. The canonical driver intentionally stores observer receipts outside that directory, so those loops continued after the expected refusal until the outer 1,200-second command watchdog stopped them. Their Session contents, external process receipts, and logs are preserved under `results/refusals/`. The independent q16 refusal runs below use the actual external receipt path and finish on the first refusal.
- One q16 refusal test run placed its stdout logs inside the strict Session directory. Reopen correctly rejected the modified Session with `MR0 Session: unsupported store entry`. This failed harness attempt is preserved under `results/refusals/LinkedHashMapPutHashTyped-q16/`; the test was rerun in a fresh separate `-q16-clean` world with logs outside Session and passed its atomic raw-refusal check. No files were removed or overwritten in those failed attempts.
- All measured EVM calls stayed within the existing 1,000,000,000 ordinary gas budget. The 150-class high-index fixture used 967,578,265 aggregate EVM gas across setup and execution; its largest individual call used 139,015,202 gas. No budget increase or runtime/consensus change was needed.

No original Minecraft JAR, class, resource, world, parent review, performance-review evidence, network, or other worktree was used.
