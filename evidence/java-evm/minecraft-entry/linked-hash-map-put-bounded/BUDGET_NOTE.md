# P59 generated-test budget adjustment

The first generated fixture `tests/put-probe.zip` used two trusted Java 8-targeted classes (`PutProbe`, `ProbeKey`). The canonical driver was first run at 1,000,000,000 ordinary gas, 65,536 quantum, with a finite 1,200-second outer tool watchdog. Its start call failed with `LC0ControlError(7)` (gas remaining at/below the unchanged 25,000,000 commit reserve), consuming 960,087,637 observed gas; the complete call was measured in the durable failed-world receipt at `tests/reports/world-basic-q2b/start-refusal.json`. The separate outer time was <1,200 seconds and observed max-call time in `process-1634105.json` was 715ms.

Per the approved measured-shortage rule, only this candidate's test-driver ordinary call ceiling is doubled to 2,000,000,000. EVM gas charging, commit reserve, local engine quotas, accepted profiles, and consensus rules are unchanged. The 1B attempt/world and labels are retained. The next run uses a new world path and 2B labels. No MAX-generated mode is enabled.

The first doubled 2,000,000,000-gas run also hit unchanged `LC0ControlError(7)`, observed gas 1,944,342,256 with the same 25,000,000 reserve. This is a measured driver/EVM call-budget limitation (including nested call gas forwarding), not a guest capability result. The candidate driver ceiling is therefore doubled once more to 4,000,000,000 for the next fresh world; both 1B and 2B failed worlds remain preserved with their receipts. No global engine or accepted quota changes.

The later fixture extension added two repeated content-hash probes (fresh raw key/value callback counts). Under the 4B driver ceiling the run hit an empty-revert/OOG at observed gas 3,937,502,163; the receipt is preserved in `tests/reports/world-basic-extended/start-refusal.json`. The ceiling was doubled to 8B. The extended content-hash fixture then completed at 4,062,192,293 gas; after adding explicit empty-iterator CME-before-NSEE and ArrayStoreException probes, the final typed-array fixture completed at 4,404,563,896 gas in `tests/reports/world-basic-typed-final/start.json`. This validates 8B as sufficient for these generated cases, not as a Java/EVM semantic limit. Earlier 1B/2B/4B labels and worlds remain intact; accepted/global budgets and EVM rules are unchanged.
